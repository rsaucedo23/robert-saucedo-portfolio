How This Site Supports Accessibility

Current accessibility practices

  • Semantic headings, landmarks, and section labels support screen-reader navigation.
  • A skip link allows keyboard users to move directly to the main content.
  • Keyboard focus states are visible across navigation, buttons, links, and controls.
  • Color contrast is tuned for readable text in both light and dark themes.
  • The theme toggle exposes its current state to assistive technology via ARIA labels.
  • External links and downloadable resume links use descriptive accessible names.
  • Resume PDFs are text-based and kept clean to preserve ATS compatibility.
  • All images include descriptive alt text.
  • The page is fully navigable by keyboard alone — no mouse required.
  • Mobile layout is responsive and tested at common viewport sizes.

Known scope

The primary portfolio and downloadable resume files are maintained as static assets. I review the site after significant updates and keep download labels, headings, contrast, focus behavior, and mobile layout in scope for each content pass.

Feedback

If you find an accessibility issue on this site, email rsaucedo23@live.com with the page, browser, assistive technology if applicable, and a short description of the issue. I aim to respond within 5 business days.
